# 🔐 Brute Forcer GUI - Hacker Style

An advanced password generator based on brute-force logic, with a powerful **GUI built in Python**.  
Designed with a **hacker-style dark theme**, this tool lets you generate millions of passwords with full control over character sets and output options.
*A dark-themed GUI with terminal-style output window.*

---

## 🧠 Features

- 💻 Hacker-themed interface (black background, neon green text, terminal font).
- 🔢 Custom password length (brute-force combinations).
- 🧩 Full charset control:
  - Numbers
  - Lowercase letters
  - Uppercase letters
  - Special characters
  - Mixed combinations
- 💾 Two output modes:
  - Display in GUI
  - Save to `.txt` file
- ⚠️ Warns on large generation (1M+ passwords)
- ✋ Stops GUI output at 100,000 lines to prevent freezing

---

## ⚙️ How It Works

1. Enter desired **password length**
2. Choose a **character set**
3. Select **output method**:
   - Show results in the terminal-style window
   - Save passwords to file
4. Click **Generate**
5. Done!
